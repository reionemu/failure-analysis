# reionemu Failure Analysis

This repository contains an analysis of the failures of `reionemu` as part of EN.601.687: Machine Learning: Coping with Non-Stationary Environments and Errors taught by [Dr. Anqi (Angie) Liu](https://anqiliu-ai.github.io/).

The `reionemu` emulator is a machine learning model that predicts the kinetic Sunyaev-Zel'dovich (kSZ) rescaled angular power spectrum ($D_\ell$) from the `zreion` simulation parameters ($\bar{z}$, $\alpha$, $k_b$, and $b_0$). This emulator acts as a fast surrogate model, allowing researchers to circumvent running computationally expensive simulations.

To make this model more appealing to reionization researchers, we opted to add uncertainty quantification with Monte Carlo Dropout. The goal of adding MC-dropout is to quantify the models' predictive uncertainty. In the notebook, [uq_failure_analysis.ipynb](/notebooks/uq_failure_analysis.ipynb), I investigate the failures of the predictive uncertainty produced by MC-dropout. Then in the notebook [uq_failure_analysis_larger_model.ipynb](/notebooks/uq_failure_analysis_larger_model.ipynb), I investigate whether the failures are improved through scaling to larger models. Finally, in the notebook [uq_failure_analysis_llm.ipynb](/notebooks/uq_failure_analysis_llm.ipynb), I investigate whether the failures are improved through the use of a frontier model (ChatGPT-6).
